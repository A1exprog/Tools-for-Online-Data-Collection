# Правовой чек-лист

| Пункт | Ответ |
|---|---|
| Источник(и) и их назначение | **quotes.toscrape.com** — учебная площадка Zyte для отработки скрапинга (цитаты, авторы, теги; версия `/js/` рендерится JavaScript, поэтому нужен браузер). **httpbin.org** — публичный сервис для тестирования HTTP: ETag/Last-Modified, коды ответа, задержки. **127.0.0.1:8765** — собственный локальный стенд-заглушка (`src/stub_server.py`) для синтетических сбоев: капча, 403, серия 503, 429, 401 |
| Цель сбора и её правомерность | Учебная: отработка устойчивого и вежливого сбора. Площадки созданы для такого использования; коммерческого использования и публикации данных нет |
| Проверка условий использования: есть ли запрет автоматического сбора | quotes.toscrape.com прямо предназначен для скрапинга, запрета нет. httpbin.org — открытый тестовый сервис, автоматические запросы и есть его назначение; нагрузку держим минимальной |
| robots.txt: релевантные правила, Crawl-delay, результат can_fetch | Проверяется кодом (`python run.py robots` → `state/robots.json`). quotes.toscrape.com и httpbin.org: ответ 404 — файла нет. По RFC 9309 это значит «ограничений нет», `can_fetch` = True для всех путей, Crawl-delay и Sitemap не заданы. Если Crawl-delay появится, ограничитель автоматически снизит скорость до 1/Crawl-delay |
| Используется ли доступ из-под авторизации | Нет. Страница /login не используется. Сценарий 401 воспроизводится только на собственном стенде |
| Применяются ли средства обхода защиты | **Нет.** Капча не решается: при её обнаружении сбор домена останавливается. Отпечатки браузера не подделываются, IP и User-Agent не ротируются, блокировки не обходятся |
| Объём и частота запросов, пиковая нагрузка на домен | Прогон ≈ 27 запросов, из них к quotes.toscrape.com ≈ 23. Не более 0,5 запроса/с на домен, всплеск ≤ 2, джиттер 20–30 %. Адаптивная задержка увеличивает интервал при росте латентности и при 429/503. Наивный прогон A (без лимитов) — один раз, ≤ 30 запросов, только на учебной площадке |
| Состав данных; есть ли персональные данные | Тексты цитат, имена авторов, даты и места рождения, биографии из открытой учебной базы. Это публичные сведения об известных, в основном умерших людях; данных пользователей и контактов нет. ПДн в смысле 152-ФЗ не обрабатываются целенаправленно |
| Правовое основание обработки (при наличии ПДн) | Целенаправленной обработки ПДн нет. При переносе на реальные сайты с ПДн основание определяется по ст. 6 152-ФЗ / ст. 6 GDPR; «общедоступность» сама по себе не даёт права на сбор (ст. 10.1 152-ФЗ) |
| Место и срок хранения, порядок удаления | Локально в папке проекта: `logs/`, `state/`, `reports/`. Тела ответов хранятся только для инцидентов (`logs/incidents/`) и в кэше 304 (`state/http_cache/`). Срок — до защиты работы, затем папки удаляются целиком. В репозиторий кэш и инциденты не коммитятся |
| Контакт для связи, указанный в User-Agent | `EducationalCrawler/1.0 (+https://example.edu; contact: student@example.edu)`. Перед реальным запуском указать свой адрес |
| Действия при получении претензии или блокировки | Сбор домена останавливается автоматически: вердикт детектора «блокировка», 403 или маркеры капчи. Артефакты сохраняются в `logs/incidents/`, процесс завершается с кодом 2. Повторный запуск — только после разбора инцидента. При претензии владельца сбор прекращается, собранные данные удаляются, причина фиксируется |
