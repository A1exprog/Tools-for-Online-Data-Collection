# Паспорт данных (data card)

## Назначение
Учебный набор для ответа на вопрос: *как соотносятся цены и ассортимент двух учебных интернет-магазинов
в сопоставимых товарных группах и связаны ли цена и скидка с рейтингом и отзывами?*
Не предназначен для выводов о реальном рынке.

## Происхождение

| Источник | Способ получения | Условия использования |
|---|---|---|
| scrapingcourse.com/ecommerce | HTML-скрейпинг (`requests` + `BeautifulSoup`), листинг + карточки | учебная площадка, созданная для отработки сбора данных; robots.txt соблюдается |
| dummyjson.com/products | REST API, `limit/skip`, `select` | открытый бесплатный API с фиктивными данными для тестирования и обучения |

Каждая строка `raw/` содержит: `stream, run_id, source, url, fetched_at, http_status, page_sha256,
parser_version, record_hash, payload`.

## Состав (чистый слой и БД)

**products** (≈ 382 строки: ≈ 188 HTML + 194 API)

| Поле | Тип | Обяз. | Описание |
|---|---|---|---|
| business_key | TEXT, PK | да | `scrapingcourse:<slug>` / `dummyjson:<id>` |
| source, source_id | TEXT | да | источник и его идентификатор |
| title | TEXT | да | название (пробелы нормализованы) |
| brand | TEXT | нет | только API |
| category_raw | TEXT | нет | исходная категория (HTML — цепочка через « \| ») |
| product_group | TEXT, FK | да | единая товарная группа — **связь источников** |
| price_usd | REAL | да | текущая цена, 0 < x ≤ 100 000 |
| regular_price_usd | REAL | нет | цена до скидки (API — восстановлена из `discountPercentage`) |
| discount_pct | REAL | нет | 0…100 |
| rating | REAL | нет | 0…5 (фактически только API) |
| review_count | INT | да | ≥ 0 |
| stock_qty | INT | нет | остаток (API; HTML — если указан) |
| in_stock | INT (0/1) | да | наличие |
| sku, url | TEXT | нет | артикул, ссылка |
| extra_json | TEXT (JSON) | да | разнородные атрибуты: теги, вариации, атрибуты размеров, статус наличия, даты meta |
| content_hash | TEXT | да | хэш содержимого — основа идемпотентного UPSERT |
| collected_at, first_seen_at, updated_at, parser_version, last_run_id | TEXT | да | служебные поля |

**reviews** (≈ 582 строки) — `review_key` (PK), `product_key` (FK → products), `rating` 1…5,
`comment`, `review_date`, служебные поля. **Без имени и e-mail автора.**

**product_history** — версии цены/скидки/наличия (`valid_from`, `valid_to`), заполняется триггерами.
**runs** — журнал прогонов (объёмы, коды, качество) для сравнения с предыдущим прогоном.

## Частота обновления
Ежедневно в 06:00 (n8n Schedule Trigger). Повторные прогоны инкрементальные (304, водяные знаки).

## Качество
11 метрик с порогами WARN/CRITICAL (`config.yaml → quality`), отчёт `reports/quality_<run>.json`,
отбракованные записи с причиной — `clean/rejects.jsonl`, протокол очистки — `clean/cleaning_protocol.json`.

## Известные ограничения
* Данные синтетические (учебные каталоги): цены, рейтинги и отзывы не описывают реальный рынок.
* Пересечение ассортимента — несколько групп, внутри групп малые выборки.
* Товарная группа HTML-товара назначается правилами по ключевым словам — возможны ошибки.
* Рейтинг и отзывы есть только у API; в HTML-каталоге их нет или почти нет.
* Удалённые с сайта товары остаются в БД (последняя известная версия); признак «снят с продажи» не ведётся.
* Валюта USD; налоги, доставка, региональные цены не учитываются.

## Лицензия / условия
Учебные площадки, использование — в образовательных целях; данные не публикуются и не перепродаются.
Срок хранения: raw — 90 дней, clean/БД — 365 дней (см. `docs/legal_checklist.md`).

## Контакт
Указан в `User-Agent` (`config.yaml → http.user_agent`) и в `legal.contact_email`.
