## История вопроса robots.txt (для честного ответа на защите)

1. Первая версия читала robots.txt стандартным `urllib.robotparser`. В Python 3.10 он не понимает `*` в
   путях и счёл `/ecommerce/` разрешённым — первые прогоны прошли, хотя правило сайта их запрещало.
2. Ошибка найдена при подготовке к защите (диагностика `python -m src.diagnose` теперь печатает вердикт
   по RFC 9309: `/ecommerce/` — ЗАПРЕЩЕНО правилом `Disallow: /ecommerce/*`).
3. Парсер заменён на собственную реализацию RFC 9309 с тестами; для учебной площадки добавлено явное
   исключение с обоснованием и журналированием, а не «тихий» обход.
4. Если преподаватель исключение не одобрит: удалить его из `config.yaml` — HTML-источник перестанет
   собираться (`robots_disallowed`), и нужно будет заменить его другой учебной площадкой.
